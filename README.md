# CylinderKnot's CCS Editor
Custom level editor for Candy Crush Saga by CylinderKnot

Current version: 0.2.1

## How to run
Download everything and double-click the `index.html` file. The editor will open in your browser.

You will need to have all the image folders, index.html, script.js, and styles.css for the editor to work properly.

In detail:
1. Find the Releases section of the main GitHub page.
2. Click on the latest release. Higher version numbers are more recent.
3. Download the source code. (For Windows and macOS, it is the zip file. For Linux, it is the tar.gz file.)
4. Extract the contents of the zip file.
5. Double-click the `index.html` file to run the editor.

**Note:** If you are cloning the repository locally, everything will be automatically downloaded.

## Features
CylinderKnot's CCS Editor has features that are absent from other available editors:
- Lightweight and open-source
- Layer-based editing, allowing you to edit specific layers of the level without modifying anything else (in progress)
- Toggleable visibility for each layer, allowing you to choose what you see whenever you want
- A separate "edit mode" for changing attributes of individual elements (not yet implemented)
- All elements from modern Candy Crush Saga (as of game version 1.300.0.2) (not yet implemented)
